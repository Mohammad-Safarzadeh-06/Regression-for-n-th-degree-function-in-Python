In the first line, enter the number of even numbers.
The even numbers are entered in the format
4:6
This means x=4 and y=6.
After entering the even numbers, it asks you for the degree of the function.
After entering all the inputs, it finds the function with the least error and displays it to you.
After that, in an infinite loop, it takes the input x from you and prints the output of the function for that value.

In the future, I will post a video tutorial explaining this code and the code itself in this repository.
